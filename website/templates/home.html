Named for Miranda Serena Sharifi of Beggars in Spain, whose thought-strings had "structural flaws from the beginning, gaps where information ought to go." A wheel ships the code and not the context around it: its identity, its advisory sources, what it has deprecated and what replaced it. This standard puts that context inside the artifact. Start here

  • You publish a Python wheel. The Production Map says what to build first. Miri Core, {{ core_count }} checks on identity, security and lifecycle, is the place to start.
  • You ship a command-line tool. The CLI Production Map says what a CLI author builds first, and which checks depend on which.
  • You build an agent or a tool that reads packages. The Consumption Map says what to read for each task and what never to conclude from it.
  • You serve metadata to agents. The Discovery Contract defines the eight read-only operations a server answers.

There is no public linter yet. The check definitions and the fixture suites to test one against are on Downloads.

A consumer is a program that asks for metadata and then decides what to believe: an agent, a linter, a CLI. A surface is a program that serves metadata in answer to queries without deciding anything about it.

Every check and schema ships as one installable package, pinned to the commit it was built from. Downloads →

The model

Each requirement in a specification is verified by a check; each check failure instance is a violation. Two scores follow. The conformance score is the weight of the passing checks over the weight of the checks that applied and could be assessed. Weights are fixed and sum to 100 per target, and any failing MUST caps the score at 74. Fixed weights are what let independent linters produce comparable scores. The health score grades how much is wrong, from each check's canonical severity and the number of violations it found.

Principles

  • Declare sources, not verdicts. Artifacts declare identity (purl) and advisory sources; consumers compute verdicts at call time.
  • Reuse the existing stack. Identity is purl; advisories are OSV records; SBOMs follow PEP 770 and CycloneDX/SPDX.
  • Same shape for open source and private. Private artifacts differ only in values, never in structure.
  • Schema as data, derived outputs. One source generates human docs and machine metadata.
  • Deprecation coherence. Markers, changelog, and removals must agree; no silent removals.
  • Citation trail. Every normative statement cites the standard it derives from.
