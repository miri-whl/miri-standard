The model

Each requirement in a specification is verified by a check; each check failure instance is a violation. Two scores follow. The conformance score is additive — fixed weights summing to 100, any failing MUST caps at 74 — and comparable across independent linters. The health score is the severity-graded magnitude of what is wrong, computed from committee-assigned severities and violation units. Populations are reported, never scored.

Principles

  • Declare sources, not verdicts. Artifacts declare identity (purl) and advisory sources; consumers compute verdicts at call time.
  • Reuse the existing stack. Identity is purl; advisories are OSV records; SBOMs follow PEP 770 and CycloneDX/SPDX.
  • Same shape for open source and private. Private artifacts differ only in values, never in structure.
  • Schema as data, derived outputs. One source generates human docs and machine metadata.
  • Deprecation coherence. Markers, changelog, and removals must agree; no silent removals.
  • Citation trail. Every normative statement cites the standard it derives from.
