# SIG-Community

The Community Special Interest Group (SIG-Community) is responsible for community building, outreach, governance, and ensuring the health and growth of the miri-standard project community.

## Scope

SIG-Community focuses on:

- **Community Building**: Growing and nurturing the contributor community
- **Governance**: Maintaining and evolving project governance processes
- **Outreach**: Promoting the project and engaging with external communities
- **Events**: Organizing community meetings, conferences, and workshops
- **Documentation**: Maintaining community-focused documentation
- **Onboarding**: Helping new contributors get started

## How to Contribute

### Join the SIG

1. Attend a SIG-Community meeting
2. Introduce yourself in GitHub Discussions
3. Review current initiatives and find areas of interest
4. Start contributing to discussions and projects

### Areas of Contribution

- **Event Planning**: Help organize community events and meetings
- **Documentation**: Improve community documentation and guides
- **Outreach**: Represent the project at conferences and meetups
- **Governance**: Participate in governance discussions and process improvement
- **Mentoring**: Help onboard new contributors
- **Communication**: Manage community communications and social media
